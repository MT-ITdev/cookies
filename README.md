# Trendy Cookies

Лендинг и мини-магазин пекарни печенья. Одностраничное приложение на Angular: анимированный hero-блок, каталог из 12 видов печенья с фильтром «Все / Без сахара», блок о пекарне и форма оформления заказа.

**[Смотреть демо →](https://mt-itdev.github.io/cookies/)**

## Что реализовано

- каталог товаров с карточками (фото, описание, цена, вес)
- переключатель фильтра по категории
- секция «о пекарне»
- форма заказа с выбором товара и контактными данными

## Стек

Angular, TypeScript, HTML, CSS · деплой на GitHub Pages
